# 西国立志編（さいごくりっしへん）

星羅の文庫（せいらのふみぐら）の一作品です。著作権の保護期間が満了した本から起こした本文を、誰でも読み・使い・直せるように置いています。

| 著者 | サミュエル・スマイルズ 著、中村正直 訳 |
| 分類 | 文語訳の洋書 |
| 分量 | 7段落・353字 |
| 状態 | 下校正済み |

見本として冒頭だけを収めた。二つの版の画像を照らし合わせて本文を作った

## 底本

- [西国立志編 : 原名・自助論 改正](https://dl.ndl.go.jp/pid/755564)（博文館・1894年）。活字で読みやすい。この本は蔵書印が本文にかかる所がある
- [西国立志編 : 原名・自助論 第 1 冊](https://dl.ndl.go.jp/pid/1080981)（木平愛二ほか・1871年）。最初の版。頭注がある。句読点は「.」で、漢文の序は句点が少ない

二つの版を補い合う。句読点と字体は明治 27 年の活字版に従い、活字版で読めない所・欠ける所を明治 4 年の初版で補う。字の違いは版ごとの本文に残す
